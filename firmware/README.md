# firmware — 设备侧说明

Cloudpath 是上位机侧平台（edge + server + 管理台），**不含任何厂商固件、SDK 或库文件**。
设备侧只需要满足 [docs/protocol.md](../docs/protocol.md) 描述的串口契约：

- 能响应单字节命令（如状态转储、对时、触发动作）；
- 状态转储以 `\n` 结尾的 ASCII 行输出；
- 业务事件单独成行输出（标签由适配器归一化）。

参考实现：`cloud-path-driver-stcb`（独立仓库）对接的 STC-B 学习板（C 固件，Keil 工具链），其固件不在此仓库内。
接入自己的设备时，通常改适配器就够了；只有当设备协议不满足上面的契约时才需要动固件。

## 固件侧设计建议（写自己的设备时参考）

1. **命令缓冲只有 1 字节也可以**：上位机侧逐字节慢发即可（见 `cloud-path-driver-stcb` 的 `sync`）。
2. **状态转储要幂等、可重复请求**：上位机按固定周期轮询，不会改动设备状态。
3. **事件行不要带时间戳**：时间由 edge 打点（设备钟不可信）。
4. **响铃/电机等大电流动作会干扰 UART**：解析器要容忍损坏行，固件侧最好把 TX 让到动作之后。
5. **掉电即失真的时钟要有对时通道**：上电后等上位机对时，再进入正常业务。
